# WEB_UI.md — веб-интерфейс

## Стек
Vue 3 + TypeScript + Vite + Vue Router. API client отдельно от UI. Для HLS — hls.js при необходимости, после проверки совместимости.

## Экраны
### Search/Home
Поле поиска, кнопка, состояния idle/loading/results/empty/partial failure/error. Год — необязательный фильтр. Не показывать недостоверные метаданные.

### Results
Карточки с названием, годом, размером, качеством/языком только если известны, провайдером и кнопкой выбора. Сбои отдельных провайдеров не скрывают успешные результаты.

### Resolve/source selection
Показывать resolving, ожидание metadata, выбор файла, подготовку потока. Если файлов несколько, предложить выбрать видео. Кнопка отмены.

### Player
HLS playback, loading/buffering/error, play/pause, seek, volume, fullscreen. Остановка сессии при выходе. Поддержку аудио/субтитров проверять по фактическому pipeline.

### Diagnostics
Версия, health, включённые провайдеры и безопасный статус. Не показывать токены, cookies, полный magnet URI или внутренние пути.

## UX
Адаптивный интерфейс, доступность с клавиатуры, явные ошибки и retry. Не сохранять секреты в localStorage без необходимости.

## Структура
`api/`, `components/`, `views/`, `router/`, `types/`, `composables/`.
