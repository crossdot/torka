# PRODUCT.md

## Видение
Лёгкий self-hosted сервис поиска метаданных и torrent-источников и потокового воспроизведения разрешённого контента. Пользователь выбирает источник и начинает просмотр без предварительной загрузки всего файла. Torrent engine может требовать ограниченный временный кэш частей.

## Цели MVP
- Rust + Axum + Tokio + Serde.
- Vue 3 + TypeScript + Vite.
- Docker для Synology DSM.
- Поисковая абстракция с кандидатами RuTracker и Rutor при наличии допустимого и технически устойчивого способа интеграции.
- Сбои провайдеров изолированы.
- Playback через torrent engine и FFmpeg; HLS — основной кандидат для web.
- Клиент-независимый HTTP API для web, будущего Android TV и других клиентов.
- Без обязательной БД и Redis; состояние сессий в памяти.
- Ограничения ресурсов, тайм-ауты, логи и корректное завершение процессов.

## Не-цели
- Android TV приложение в MVP.
- Пользовательские профили, избранное и история.
- PostgreSQL/Redis, микросервисы, Kubernetes.
- Динамические бинарные плагины.
- Обход CAPTCHA, paywall, аутентификации, антибот-защиты или иных ограничений.
- Гарантия доступности внешних сайтов или раздач.

## Сценарии
1. Поиск: запрос → параллельные провайдеры → нормализованные результаты → частичные результаты при сбое одного источника.
2. Выбор: валидировать opaque source ID, разрешить torrent metadata, выбрать видеофайл.
3. Playback: создать сессию → подготовить поток → клиент получает HLS → остановить сессию → очистить ресурсы.

## Принципы
- Не добавлять инфраструктуру без необходимости.
- Не выдумывать неизвестные метаданные.
- Не логировать секреты и полный magnet URI.
- Не создавать постоянные копии видео; временный кэш ограничен и очищается.
